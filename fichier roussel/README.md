🌐 Projet Madame Roussel

Date : 07/10/2026
Formation : Développeur Web et Web Mobile (DWWM)
Type de projet : Retour de ticket client – Découverte du Web

📖 Présentation du projet

Ce projet a été réalisé dans le cadre de ma formation Développeur Web et Web Mobile.

L'objectif est de découvrir et de comprendre les bases du fonctionnement d'Internet et du Web, tout en apprenant à analyser et à résoudre des problèmes rencontrés par une cliente fictive, Madame Roussel.

Le travail est divisé en cinq parties, allant des définitions techniques à la rédaction d'une réponse professionnelle destinée à la cliente.

📂 Contenu du projet

Partie A – Définitions du Web

Recherche et définition des principaux termes utilisés dans le développement web.

Notions abordées :

Internet et Web

Client et serveur

Navigateur

Nom de domaine et hébergement

DNS et URL

HTTP et HTTPS

Requête et réponse HTTP

Codes de statut

API

Partie B – Analyse des URL

Étude de trois adresses web afin d'identifier leurs différents composants :

Le protocole

Le sous-domaine

Le nom de domaine

L'extension

Le chemin

Les paramètres

Cette partie permet de comprendre la structure et le fonctionnement d'une URL.

Partie C – Fonctionnement d'une page web

Réalisation d'un schéma expliquant les différentes étapes nécessaires à l'affichage d'une page web, depuis la saisie de l'URL jusqu'à son affichage dans le navigateur.

Partie D – Identification des langages web

Analyse et classement de huit extraits de code selon les trois principaux langages du développement web :

HTML : structure et contenu d'une page web.

CSS : mise en forme et apparence visuelle.

JavaScript : interactions et fonctionnalités dynamiques.

Partie E – Résolution du ticket client

Analyse des problèmes rencontrés par Madame Roussel et rédaction d'une réponse professionnelle.

Problèmes étudiés :

Erreur 404 : comprendre pourquoi une page est introuvable et proposer des solutions.

Blog non sécurisé : expliquer la différence entre HTTP et HTTPS et l'importance de sécuriser les échanges.

Nom de domaine et hébergement : expliquer leurs rôles et les conséquences d'un non-renouvellement.

🎯 Objectifs pédagogiques

Ce projet permet de :

Comprendre les bases d'Internet et du Web.

Identifier les composants d'une URL.

Comprendre les échanges entre un client et un serveur.

Reconnaître les langages HTML, CSS et JavaScript.

Identifier des erreurs courantes sur un site web.

Proposer des solutions adaptées aux problèmes d'un client.

Développer une communication professionnelle.

📝 Conclusion

Ce projet m'a permis d'acquérir des connaissances essentielles sur le fonctionnement du Web et les technologies utilisées pour créer et consulter des sites internet.

Il m'a également permis de mettre en pratique ces connaissances à travers un cas concret, en analysant les problèmes d'une cliente et en proposant des solutions adaptées.

Ce travail constitue une première étape dans mon apprentissage du métier de développeur web.
