Définition :
-	Internet : internet est un vaste réseau d’ordinateur qui communiquent entre eux.
Source : https://developer.mozilla.org/fr/docs/Learn_web_development/Howto/Web_mechanics/How_does_the_Internet_work

-	Web : web est un système d'information qui permet de consulter des pages reliées entre elles par des hyperliens, le tout accessible sur Internet à l'aide d'un navigateur comme google ou modzilla Firefox.
Source : https://fr.wikipedia.org/wiki/World_Wide_Web

-	Client : ce sont des appareils connectés à internet comme un ordinateur relié au wifi et les logiciels qui permette d’accéder au web comme des navigateur.
Source : https://developer.mozilla.org/fr/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works

-	Serveur : ce sont des machines qui serve à stocker des pages web, des sites, application, et qui peuvent être consulter par des clients.
Source : https://developer.mozilla.org/fr/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works

-	Navigateur : c’est un logiciel installé sur votre appareil (ordinateur, téléphone, etc…) qui permet de d’accéder à internet et consulter des sites web.
Source : https://www.firefox.com/fr/more/what-is-a-browser/

-	Nom de domaine : c’est l’équivalent de l’adresse postale du site web ou application sur internet, c’est aussi la traduction mémorisable de l’adresse IP.
Source : https://www.afnic.fr/noms-de-domaine/tout-savoir/

-	Hébergement : L’hébergement d’un site web est un espace dédié qui regroupe l’ensemble des éléments du site internet. C’est une zone de stockage qui rassemble toutes les données et les contenus de votre site.
Source : https://www.net-concept.fr/actualites/quest-ce-que-l-hebergement-dun-site-web/

-	DNS : le Domain Name System (DNS) est comme un carnet d'adresses pour les sites web. Lorsque l’ont saisie l’adresse web, le navigateur va consulter le DNS pour trouver l’adresse IP du site.
Source : https://developer.mozilla.org/fr/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works

-	URL : Uniform resource locators (URL) c’est l’adresse du site que l’ont souhaité consulter, c’est ce que l’on va taper dans la page de recherche du navigateur. Pour exemple voici une l’URL du moteur de recherche google : https://www.google.com
Source : https://www.numacom.fr/blog/qu-est-ce-qu-une-url-definition-et-fonctionnement

-	Http : (HyperText Transfer Protocol) est un protocole de communication utilisé pour le transfert de ressources et de données sur le web entre un client (navigateur) et un serveur.
Source : https://www.urbilog.com/lexique-experts/http

-	Https : c’est la version sécurisée et amélioré du protocole http, et cela permet de chiffrer les échanges de données entre le navigateur et un site web.
Source : https://www.nameshield.com/ressources/lexique/protocole-https/
 
-	Requête : (souvent appelée requête HTTP) c’est une demande envoyée par un navigateur ou une application (le client) à un serveur web pour afficher une page ou récupérer des données
Source : https://blog.hubspot.fr/website/reduire-nombre-requetes-http

-	Réponse : c’est un message envoyé par un serveur web à un client en réponse à une requête http qu’il vient de recevoir.
Source : https://brightdata.fr/glossary/http-response

-	Code de statut : c’est une suite de nombre a 3 chiffres envoyés par le serveur au navigateur pour lui indiquer le résultat de la requête. Exemple error 404 et un code de statut pour dire que la page que l’on veut consulter et introuvable.
Source : https://developer.mozilla.org/fr/docs/Web/HTTP/Reference/Status

-	Api : est une interface logicielle qui permet à deux applications ou systèmes différents de communiquer entre eux et d'échanger des données.
Source : https://www.cnil.fr/fr/definition/interface-de-programmation-dapplication-api

# réponse erreur 404 :

Cela signifie que le serveur ne trouve pas le fichier correspondant à votre page « Livraison ». Le fichier a peut-être été déplacé, renommé ou supprimé.
Dans les deux premiers cas, il faut vérifier que le fichier est bien placé au bon endroit et qu’il porte le bon nom. S’il a été supprimé et qu’aucune sauvegarde n’est disponible, il faudra faire recréer la page « Livraison » par un développeur.

# réponse sur la mention sécurité du blog :
Concernant la mention « Non sécurisé » que vous voyez sur votre blog, cela signifie que votre site utilise le protocole HTTP et non HTTPS. La principale différence est que le HTTPS permet de sécuriser et de chiffrer les échanges de données entre le site et ses visiteurs.
Avec un site en HTTP, certaines informations échangées peuvent être interceptées par un tiers. Je vous conseille donc de passer votre blog en HTTPS afin de mieux sécuriser les échanges et de rassurer vos visiteurs.
Enfin, le nom de domaine correspond à l’adresse et à l’identité de votre site web, tandis que l’hébergement correspond à l’espace dans lequel sont stockés les fichiers de votre site.
Il est important de conserver et de renouveler les deux. Si le nom de domaine n’est pas renouvelé, vous risquez de perdre l’utilisation de cette adresse. Si l’hébergement n’est pas renouvelé, le site ne sera plus accessible en ligne.
